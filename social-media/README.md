# Dwayati — Publications réseaux sociaux

Espace de préparation des campagnes Facebook / Instagram.

## Structure
- `campaigns/2026-10-26-lancement/` : textes et instructions de publication.
- `media/` : emplacement réservé aux visuels PNG et vidéos MP4 (à transférer).

## Publication
Les publications doivent indiquer que Dwayati est **en développement** ; aucune donnée patient réelle ne doit apparaître dans les démonstrations.

Les fichiers média ne sont pas encore déposés dans ce dépôt. Ne pas utiliser d'URL média avant confirmation de sa présence dans GitHub.
